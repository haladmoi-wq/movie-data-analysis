Movie Data Analysis

Overview

This project analyzes a small movie dataset using Python, Pandas, and Matplotlib.

The goal is to explore movie ratings, genres, durations, and identify the highest-rated movies.

Technologies

* Python
* Pandas
* Matplotlib

Dataset

The dataset contains information about:

* Movie title
* Genre
* Release year
* Rating
* Duration

Analysis

The project performs:

* Average movie rating calculation
* Average movie duration calculation
* Average rating by genre
* Top 5 highest-rated movies
* Visualization of average ratings by genre
* Visualization of movie duration versus rating

Results

The analysis shows differences in average ratings between genres and explores the relationship between movie duration and rating.

The top-rated movie in the dataset is The Godfather, with a rating of 9.2.

Purpose

This project was created to practice data analysis and visualization using Python and Pandas.

It is part of my AI and Data Science portfolio.
